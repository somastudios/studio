Cómo está hecho

  • Cada forma es una lista de puntos, el dibujo se arma de nuevo en cada cuadro.
  • Tres ondas recorren cada línea, dos lentas y una rápida, por eso tiembla sin brincar.
  • Un corto tiene planos, cada uno con su encuadre, y la pista de abajo marca en cuál va.
  • Las formas se vuelven otras, la puerta termina siendo el expediente y el frasco, un recibo.
  • Todo toma vuelo antes de moverse y al llegar se pasa un poco, como en la animación a mano.
  • Lo que cuelga llega tarde, el pelo y las cejas siguen a la cabeza un instante después.
  • Entre más enredada la idea, más hierve la línea, cuando se aclara casi se queda quieta.
  • Toda la escena depende del tiempo, se puede detener o capturar en cualquier instante.
// Una forma son puntos. Un trazo vivo: T(forma, opciones).
T(P.rect(44, 26, 72, 70, 8), { cls: 'ln tapa' })       // contorno que tapa lo de atrás
T(D(remuestra(PUERTA, 96)), { cls: 'ln tapa', n: 'hoja' })  // una forma que va a cambiar

// Un plano: qué cambia según el tiempo t (segundos desde que empezó ese plano).
paso(q, t) {
  const m = rebota(tramo(t, 1.9, 2.8))                 // llega y se pasa un poco
  forma(q('hoja'), mezclaPts(PUERTA, EXPEDIENTE, m))   // la puerta se vuelve expediente
  agita(q('lio'), 2.4)                                 // esta línea hierve más fuerte
  pon(q('punto'), { x: 196, y: 128, sy: 1 - 0.3 * golpe(t, 3.95, 0.2) })
}
