Trazo vivo

Las líneas tiemblan como dibujadas a mano y se calculan de nuevo en cada cuadro, a 60 por segundo.

Cómo está hecho

  • Cada forma es una lista de puntos, el dibujo se arma de nuevo en cada cuadro.
  • Tres ondas recorren cada línea, dos lentas y una rápida, por eso tiembla sin brincar.
  • En treses el reloj avanza 8 veces por segundo, es el hervor clásico de la animación a mano.
  • El bloque gris va desfasado 5 unidades, como una tinta impresa fuera de registro.
  • El punto azul es el personaje, en cada escena hace una sola cosa.
  • Toda la escena depende del tiempo, se puede detener o capturar en cualquier instante.
// Una forma son puntos. Un trazo vivo: T(forma, opciones).
T(P.rect(44, 26, 72, 70, 8), { cls: 'ln tapa' })   // contorno que tapa lo de atrás
T(P.rect(49, 31, 72, 70, 8), { cls: 'blq' })       // su bloque gris, desfasado 5

// Una escena: qué cambia según el tiempo t, en segundos. Corre en bucle cada `dur`.
paso(q, t) {
  traza(q('renglon'), suave(tramo(t, 0.3, 1.3)))   // se dibuja entre 0.3 s y 1.3 s
  pon(q('punto'), { x: 86, y: 72, sx: rebota(tramo(t, 3.5, 3.8)) })
}
